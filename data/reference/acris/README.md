# ACRIS reference examples

Official NGSI-LD "normalized" examples from the FIWARE Smart Data Models repository
[smart-data-models/dataModel.ACRIS](https://github.com/smart-data-models/dataModel.ACRIS) (CC-BY-4.0),
copied unchanged so the ACRIS adapter is tested against the public format, not only against our own mocks.

The forum confirmed this public repository is the ACRIS reference for the challenge. Real airport names
inside these files belong to the upstream examples; our generated data uses only the fictional airport.
